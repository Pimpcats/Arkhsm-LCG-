EXTRACTION RULES USED

- Source pixels only.
- No generation or recreation.
- No repainting, sharpening, denoising, or color correction.
- No enlargement of deliverable assets.
- Transparency masks were used only to remove surrounding card pixels.
- Preview sheets use nearest-neighbor enlargement so the original raster
  structure remains visible.
