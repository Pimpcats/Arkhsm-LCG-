## ⚑ Two findings to flag for design (not resolved — owner's call)

1. **Hard-reset is a campaign pressure, not a per-loop one.** Hour IX ends the
   night (~6 rounds) before Dissonance-18 can, so a single loop almost never
   hard-resets regardless of greed. The reset threat only bites late-campaign via
   the **scar floor** (greedy: 0.6% → 79% as scar climbs 0 → 6). This matches
   "the clock still wins eventually," but if you intended greedy play to risk a
   reset *within* an early loop, the per-round Dissonance gains or the loop length
   need re-tuning.

2. **The finale contest looks easy** (~95–100% reach). Hold Back both adds contest
   **and** rewinds the Hourglass, so attempts buy the time to make more attempts —
   a compounding loop. If the finale should be a real threat, consider decoupling
   (Hold Back rewinds *or* contributes contest, not both), raising the target, or
   capping Hold Back attempts per round.

*Model caveats: single-loop stress starts from a chosen scar (no in-loop Hold-Back
extension modelled in the reset test); the finale assumes every investigator
attempts Hold Back each round at a fixed success p. Table play validates the rest.*
