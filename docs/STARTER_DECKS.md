# THE STILL HOUR - Starter decks

*Owner-facing and spoiler-free. These are suggestions, not requirements: build
your own deck if you prefer.*

Each list below is a legal **30-card starting deck** for the investigator, built
only from **level 0** cards (a starting deck holds no Recollections or upgrades;
those are bought between loops). Each list was checked against the
investigator's deckbuilding options on the back of their card, the 2-copy limit
and any per-deck limits.

What is **not** counted in the 30: the cards listed under *Deckbuilding
Requirements* on the investigator's back (their signature cards) and **1 random
basic weakness**, which you add as normal.

All the cards come from official Arkham Horror: The Card Game products that
SCED's player cards include. If one of the packs named is not in your copy,
swap the card for another level 0 card of the same class and a similar cost.

Birdie and Seraphine have no suggested list here.
