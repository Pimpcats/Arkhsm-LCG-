# THE STILL HOUR — Art Spec
### v1.0 · house style, character consistency, and per-category prompt templates

The machine-readable job list is `art_manifest_starter.json` (generated by `build_art_manifest.py`). This doc is the human-readable direction behind it and the template for extending the manifest to all ~250 faces.

---

## 1. House style (the constant)

Every illustration prompt is built as: **`{character (if any)}, {scene}. {STYLE}`** with the shared negative. Keep these identical across every card so the set reads as one product.

**STYLE (append to every prompt):**
> cosmic horror illustration, painterly, muted desaturated palette, 1920s New England coastal town, eerie stillness, starless folding sky, cinematic soft lighting, oil-paint texture, subtle grain, Arkham Horror card art style, atmospheric, unsettling

**NEGATIVE (every prompt):**
> text, watermark, signature, frame, border, ui, logo, deformed hands, extra fingers, modern clothing, bright saturated colors, cartoon, 3d render, cheerful, sunny, lens flare, cluttered

**Palette anchor:** slate blue, bone, rust, lantern-amber against near-black. Amber is the *only* warm note and should read as fragile (lamplight, the one thing holding the dark back).

## 2. Character consistency (the hard part)

The five investigators recur across many cards (portrait, signatures, minicard). Two proven routes — pick per investigator:

- **LoRA (best for many cards):** generate 8–15 varied images of the canonical look, train a per-investigator LoRA on Krea (supported for Flux/Krea models), then reference `lora:{name}` in every one of that character's prompts.
- **Reference image (fastest to start):** generate one strong **canonical portrait** each, then pass it as a **weighted reference image** (Krea 2 supports up to 10 weighted references) at ~0.7 strength on all their other cards.

The manifest's `reference` field already encodes both options (`ref:{name}_canonical.png (weight 0.7)  OR  lora:{name}`). **Encounter art needs no character consistency** — only house-style consistency, handled by a shared **moodboard/style reference** (`moodboard:still_hour_style`).

**Character bibles** (the canonical look — keep these words stable):

## 3. Prompt templates by category

Each is `character/subject, {scene}. {STYLE}` + the shared negative. Scenes should be **single, legible, negative-space-friendly** — card art is small.

- **Investigator front** *(landscape)* — half-length portrait in their home location, one strong silhouette. *e.g. Elias: "standing before a dark unlit lighthouse at night, salt wind."*
- **Investigator back** *(landscape, no illustration)* — deckbuilding text only; Strange Eons renders the back, no Krea job.
- **Signature asset/event/skill** *(portrait)* — the object or a tight gesture, still-life or hands, not the full character. *e.g. The Ambergrove Lamp: "an old brass storm-lantern glowing faint amber in fog."*
- **Location** *(portrait)* — an empty, wrong-feeling place; front = this loop, back = the "remembered" calmer version once a Knowledge fact flips it. Generate both faces with a shared composition, the back lighter/stiller.
- **Echo enemy** *(portrait)* — townsfolk frozen mid-gesture, faces "turned slightly wrong," grey light. Uncanny, never gory.
- **The Latecomer** *(portrait)* — the campaign's key image: "a tall wrong silhouette at the far end of an empty street, too many angles, not quite arriving, featureless, dread, negative space." Restraint is the point — never fully resolve it.
- **Treachery** *(portrait)* — a single symbolic beat (a watch blurring forward, ink running backward, eight graves).
- **Hour cards (agenda frame)** *(landscape)* — the night escalating: the bell, the wrong sky, the road giving way.

## 4. Frame & dimension reference

Strange Eons crops the illustration into the frame, so generate generously and let SE place it.

| Frame (SE template) | Aspect | Gen size | Notes |
|---|---|---|---|
| investigator_front | landscape | 1024×768 | portrait inset in landscape card |
| investigator_back | landscape | — | text only, no Krea job |
| asset / event / skill | portrait | 768×1024 | player card art window |
| treachery / enemy | portrait | 768×1024 | often near full-bleed |
| location_front / _back | portrait | 768×1024 | two faces, shared composition |
| agenda / act | landscape | 1024×768 | the Hour cards |
| minicard | portrait | 512×768 | reuse the investigator portrait |

## 5. Extending the manifest

Add one `entry(...)` per card face in `build_art_manifest.py` (or append to the JSON), pulling text from `cards_v0.2` and `encounter_v0.4`. Keep seeds **stable per card** so re-runs are reproducible, and vary seeds only when curating alternates. Target order: 5 canonical portraits → train/collect references → the ~20 player cards → the ~37 shared encounter cards → the Hour deck → node-specific sets.
